## 🚀 Quick Start

### Prerequisites
- Flutter 3.32.0+
- Dart 3.8.0+
- Android Studio / VS Code
- Firebase project
- Razorpay account (for payments)
- Gemini API key (for AI chat)

### 1. Clone & Setup
```bash
git clone <repo>
cd fitmitra
flutter pub get
```

### 2. Firebase Setup
1. Create a Firebase project at [console.firebase.google.com](https://console.firebase.google.com)
2. Enable **Authentication** → Phone sign-in
3. Enable **Cloud Firestore**
4. Enable **Firebase Storage**
5. Add Android app with package `com.epointdigital.fitmitra`
6. Download `google-services.json` → place in `android/app/`
7. Run FlutterFire CLI:
```bash
dart pub global activate flutterfire_cli
flutterfire configure --project=your-project-id
```
This generates `lib/firebase_options.dart`.

### 3. API Keys Setup
Edit `lib/core/constants/app_constants.dart`:
```dart
static const String razorpayKeyId = 'rzp_live_XXXXXXXXXXXX';
static const String geminiApiKey = 'AIzaSyXXXXXXXXXXXXXXXX';
```

### 4. Fonts Setup (Optional but recommended)
Download Poppins font from [Google Fonts](https://fonts.google.com/specimen/Poppins):
- Poppins-Regular.ttf
- Poppins-Medium.ttf
- Poppins-SemiBold.ttf
- Poppins-Bold.ttf

Place in `assets/fonts/` directory, then add to `pubspec.yaml`:
```yaml
fonts:
  - family: Poppins
    fonts:
      - asset: assets/fonts/Poppins-Regular.ttf
      - asset: assets/fonts/Poppins-Medium.ttf
        weight: 500
      - asset: assets/fonts/Poppins-SemiBold.ttf
        weight: 600
      - asset: assets/fonts/Poppins-Bold.ttf
        weight: 700
```

### 5. Run the App
```bash
flutter run --debug          # Debug mode
flutter run --release        # Release mode
flutter build apk --release  # Build APK
flutter build appbundle      # Build AAB for Play Store
```

### Navigation: GoRouter
- Shell routes for bottom nav persistence
- Named routes for deep linking
- Auth-based redirects

## 🔧 Firestore Data Structure

```
users/{uid}
  ├── phoneNumber: string
  ├── name: string
  ├── age: number
  ├── heightCm: number
  ├── weightKg: number
  ├── gender: string
  ├── healthGoal: string
  ├── activityLevel: string
  ├── dietPreference: string
  ├── membershipType: enum (free/monthly/quarterly/annual)
  ├── membershipExpiry: timestamp
  ├── bmi: number
  ├── dailyCalorieGoal: number
  ├── dailyWaterGoalLiters: number
  ├── profileSetupDone: boolean
  └── updatedAt: timestamp

tracking/{uid}/daily/{date}
  ├── caloriesConsumed: number
  ├── waterMl: number
  ├── steps: number
  └── meals: array

chat_messages/{uid}/messages/{msgId}
  ├── content: string
  ├── role: string (user/assistant)
  └── timestamp: timestamp
```

## 📲 Play Store Release

### 1. Generate Keystore
```bash
keytool -genkey -v -keystore ~/upload-keystore.jks \
  -keyalg RSA -keysize 2048 -validity 10000 \
  -alias upload
```

### 2. Configure Signing
Create `android/key.properties`:
```properties
storePassword=YOUR_STORE_PASSWORD
keyPassword=YOUR_KEY_PASSWORD
keyAlias=upload
storeFile=/path/to/upload-keystore.jks
```

Update `android/app/build.gradle.kts`:
```kotlin
val keystoreProperties = Properties()
val keystorePropertiesFile = rootProject.file("key.properties")
if (keystorePropertiesFile.exists()) {
    keystoreProperties.load(FileInputStream(keystorePropertiesFile))
}

android {
    signingConfigs {
        create("release") {
            keyAlias = keystoreProperties["keyAlias"] as String
            keyPassword = keystoreProperties["keyPassword"] as String
            storeFile = file(keystoreProperties["storeFile"] as String)
            storePassword = keystoreProperties["storePassword"] as String
        }
    }
    buildTypes {
        release {
            signingConfig = signingConfigs.getByName("release")
        }
    }
}
```

### 3. Build & Upload
```bash
flutter build appbundle --release
# Upload android/app/build/outputs/bundle/release/app-release.aab to Play Store
```

## 🔒 Security

- All sensitive keys in `AppConstants` (use environment variables in production)
- ProGuard rules configured for release builds
- Network security config for HTTPS enforcement
- Firebase Security Rules for Firestore access control

### Recommended Firestore Security Rules
```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
    match /tracking/{userId}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
    match /chat_messages/{userId}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
  }
}
```
